# Bank Marketing Data Analysis

## Project Overview
This project focuses on acquiring, cleaning and preprocessing the Bank Marketing dataset using Python.

## Dataset
- Records: 45,211
- Original Columns: 17
- Processed Columns: 43

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Kaggle Notebook

## Tasks Completed
- Data Acquisition
- Data Cleaning
- Missing Value Checking
- Duplicate Checking
- Categorical Data Encoding
- Data Preprocessing

## Output
Preprocessed dataset saved as CSV.
